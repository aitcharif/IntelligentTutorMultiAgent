# مقدمة في بايثون - مستوى الجذع المشترك

## المتغيرات في بايثون

### ما هو المتغير؟

المتغير هو حاوية تسمح بتخزين البيانات في الذاكرة. في بايثون، لا تحتاج إلى التصريح عن نوع المتغير.

### أمثلة:

```python
# متغيرات رقمية
age = 16
note = 15.5

# متغيرات نصية
nom = "أحمد"
ville = "الدار البيضاء"

# متغيرات منطقية
est_etudiant = True
```

### قواعد التسمية:
- البدء بحرف أو (_)
- بدون مسافات (استخدم _)
- تجنب الكلمات المحجوزة في بايثون

### مثال مغربي:
```python
ville_natale = "الرباط"
nombre_de_freres = 3
parle_arabe = True
```

## العمليات الحسابية

يمكن استخدام بايثون كآلة حاسبة:

```python
# الجمع
somme = 10 + 5  # 15

# الطرح
difference = 20 - 8  # 12

# الضرب
produit = 6 * 7  # 42

# القسمة
quotient = 20 / 4  # 5.0

# القسمة الصحيحة
division_entiere = 20 // 3  # 6

# الباقي
reste = 20 % 3  # 2

# القوة
puissance = 2 ** 3  # 8
```

## أنواع البيانات

### الأنواع الأساسية:
- **int**: أعداد صحيحة (مثال: 42, -10)
- **float**: أعداد عشرية (مثال: 3.14, -2.5)
- **str**: نصوص (مثال: "مرحبا", "المغرب")
- **bool**: منطقية (True أو False)

### التحقق من النوع:
```python
age = 16
print(type(age))  # <class 'int'>

note = 15.5
print(type(note))  # <class 'float'>

nom = "أحمد"
print(type(nom))  # <class 'str'>
```

## السلاسل النصية

### الإنشاء:
```python
message = "مرحبا بالمغرب!"
prenom = 'فاطمة'
phrase = """هذا نص
على عدة أسطر"""
```

### العمليات على النصوص:
```python
# الدمج
salutation = "مرحبا " + "أحمد"

# التكرار
repeat = "ها" * 3  # "هاهاها"

# الطول
longueur = len("الدار البيضاء")

# أحرف كبيرة/صغيرة
ville = "rabat"
print(ville.upper())  # "RABAT"
```

## تمارين تطبيقية

### التمرين 1: حساب العمر
```python
# تلميذ ولد سنة 2008
# احسب عمره في 2024

annee_naissance = 2008
annee_actuelle = 2024
age = annee_actuelle - annee_naissance
print(f"عمر التلميذ: {age} سنة")
```

### التمرين 2: بطاقة الهوية
```python
# أنشئ متغيرات لملفك الشخصي
nom = "العمراني"
prenom = "يوسف"
age = 16
ville = "مراكش"

# اعرض بطاقة هويتك
print("=== بطاقة الهوية ===")
print(f"الاسم العائلي: {nom}")
print(f"الاسم الشخصي: {prenom}")
print(f"العمر: {age} سنة")
print(f"المدينة: {ville}")
```

### التمرين 3: حساب المعدل
```python
# احسب معدل ثلاث نقط
note1 = 15
note2 = 17
note3 = 14

moyenne = (note1 + note2 + note3) / 3
print(f"المعدل: {moyenne:.2f}")
```

## النقاط الأساسية

✅ المتغيرات تخزن البيانات
✅ بايثون يحدد النوع تلقائياً
✅ استخدم أسماء متغيرات واضحة
✅ النصوص يمكن أن تكون بين " " أو ' '
✅ العمليات الحسابية سهلة
